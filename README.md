#  Weather App (PyQt5)

A clean and simple desktop Weather Application built in Python using **PyQt5** and the **OpenWeatherMap API**. It allows users to search for real-time weather information for any city worldwide, complete with dynamic status emojis and error handling.

##  Features

-  **Real-Time Weather Data**: Fetches accurate temperature and weather conditions via OpenWeatherMap API.
-  **Modern Graphical Interface**: Designed with custom PyQt5 styling, clean layouts, and dynamic weather emojis.
-  **Comprehensive Error Handling**: Displays visual feedback for invalid input, bad API keys, network issues, or unknown cities (404, 401, 500 status codes).
-  **Secure Configuration**: Uses environment variables (`.env`) to securely store API keys away from public source code.

---

##  Tech Stack

- **Python 3.x**
- **PyQt5** (GUI Framework)
- **Requests** (HTTP Library)
- **python-dotenv** (Environment Management)
